# Sensei Squeegee

Website for Sensei Squeegee — interior and exterior residential window cleaning in
Flagstaff and surrounding Hamilton suburbs, NZ.

React + Vite + Tailwind, deployed on Netlify.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before launch

See [FOLLOW-UPS.md](./FOLLOW-UPS.md) — the site currently contains clearly marked
placeholders (`TODO` / `TO BE CONFIRMED`). Nothing placeholder should ship.

## House rules

- **Image filenames**: lowercase-with-hyphens only, and imports must match filenames
  exactly (Netlify's Linux build is case-sensitive; Windows hides mismatches).
- **No stock/found images** without confirmed licensing.
- **No invented testimonials, bios, or business facts** — placeholders must be clearly
  marked with `TODO` comments.
- The site offers **one service only**: residential window cleaning (interior + exterior).
